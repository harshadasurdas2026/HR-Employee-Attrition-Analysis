HR Employee Analysis Dashboard

📌 Project Overview

This Power BI project analyzes employee details, attendance, and salary data through interactive dashboards.

🛠️ Tools Used

- Power BI
- DAX
- Data Modeling

📂 Dataset

The project contains three tables:

- Employees: Employee details, age, department, gender, and job role.
- Attendance: Attendance date, status, and hours worked.
- Salary: Monthly salary, bonus, and salary grade.

📊 Dashboard Pages

1. HR Overview: Employee count, average age, salary, and department-wise analysis.
2. Attendance Analysis: Attendance status, total hours worked, and department-wise attendance analysis.
3. Salary Analysis: Average monthly salary and salary comparison by grade.

💡 Key Insights

- Provides an overview of employee distribution across departments.
- Shows attendance status and working hours.
- Compares average salaries across different salary grades.
- Helps understand workforce and salary trends.
